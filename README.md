# damier

Basic local damier game built with plain HTML, CSS, and JavaScript.

## Run locally

Open `/home/runner/work/damier/damier/index.html` in a browser, or serve the repository with a simple static file server:

```bash
cd /home/runner/work/damier/damier
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Current features

- Two-player local play on one machine
- Turn-based movement
- Diagonal captures
- King promotion
- Multi-capture turns when available
- Restart button

This provides a basic playable foundation that can later be expanded into a networked multiplayer version.
